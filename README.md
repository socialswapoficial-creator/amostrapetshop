# Pata & Cia — Pet Shop

Landing page em HTML, CSS e JavaScript, com imagens responsivas, catálogo, busca, favoritos, carrinho e formulário de agendamento.

## Publicar na Vercel

- Framework Preset: Other
- Root Directory: raiz do repositório
- Build Command: vazio (sem build)
- Output Directory: dist
- Install Command: vazio

O arquivo vercel.json já define as configurações principais.

Produtos, preços e depoimentos são fictícios. Pagamentos, agendamentos e newsletter não estão conectados a serviços externos.

## Arquivos

- dist/index.html
- dist/style.css
- dist/app.js
- dist/assets/ — imagens WebP com versões responsivas e arquivos de 3840 pixels de largura.
